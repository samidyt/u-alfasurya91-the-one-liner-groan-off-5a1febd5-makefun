## The joke

A dinner-table dad joke with a double pun: the bread rises to the occasion, then crumbles under pressure. One line, 80 characters, no setup beyond the line itself — the punchline lands in the second half and the groan is the whole point.

## Run

```sh
node main.ts   # writes the one-liner to /output/entry.txt
```

Requires Node 22.18+ (TypeScript runs as-is). No dependencies, no network, no secrets.
